# 博士生科研工作台 PRD（完整版）

## 1. 产品定位

**名称：** Research Workbench（科研工作台）  
**一句话：** 面向 AI 算法方向博士生的本地个人科研操作系统。  
**使用场景：** 仅个人使用；数据本地存储；支持整库导入/导出。  
**学科形态：** AI / 机器学习算法研究（文献、实验 Run、投稿、论文章节为高频路径）。

### 1.1 目标与非目标

**目标**
- 统一管理：文献、项目/实验、任务、日历、学术产出、会议、毕业论文
- 文献深度：PDF 批注 + 关联研究笔记 + 分类 + 批量主题阅读 + 本地目录关联
- 总览首页：打卡、专注、任务进度、请假/状态、近期限节点
- 本地优先：SQLite + 本地文件路径；ZIP/JSON 备份迁移

**非目标（本版不做）**
- 多用户账号、权限、协作编辑
- 云同步与 SaaS 登录
- 自动爬虫抓取全文、代写论文
- 集群调度 / WandB 深度集成（预留字段即可）

## 2. 用户与场景

| 角色 | 说明 |
|------|------|
| 博士生本人 | 唯一用户，本地单机 |

**关键场景**
1. 从本地论文目录入库 → 阅读批注 → 写研究笔记 → 挂到项目/论文章节
   - 阅读队列自动流转：未打开＝待读，打开无笔记＝待精读，有笔记＝已精读
2. 管理在研算法实验（假设、参数、结果路径、结论）
3. 跟踪会议/期刊投稿状态与 DDL
4. 组会记录转任务
5. 毕业论文章节推进与学校节点
6. 每日打卡/专注推进阅读或写作
7. 整库导出备份或换机导入

## 3. 信息架构

```
首页 Dashboard
文献 Library
项目 Projects（申请 / 在研 / 实验）
任务 Tasks
日历 Calendar
产出 Outputs（投稿 / 专利 / 期刊库 / 会议库）
会议 Meetings
论文 Thesis
设置 Settings（监视目录、导入导出、偏好）
```

## 4. 功能需求详述

### 4.1 首页
- 今日焦点项目与 Next Actions（最多 5 条）
- 任务进度：今日完成/总数、逾期数
- 近 7 日日历条：DDL、会议、答辩节点
- 打卡：阅读日 / 实验日 / 写作日（可自定义备注）
- 专注计时：绑定任务或文献，结束后记一条会话
- 个人状态：在岗 / 请假 / 外出实验；请假写入日历占用
- Inbox：快速捕获想法/链接，在札记页整理为想法、任务或文献笔记

### 4.2 文献管理
1. **PDF 批注**：高亮/笔记，含页码、颜色、选区文本、评论；侧栏列表；跳转页
2. **研究笔记**：与 PDF 关联的结构化笔记（动机、问题、方法、结果、局限、与我课题关系、可引用点）
3. **分类管理**：文件夹、标签、阅读状态、相关度、项目关联、类型
4. **批量**：多选改元数据；批量生成研究笔记模板；主题阅读会话（多篇切换 + 共享标签聚合）
5. **本地文件系统**：配置监视根目录；树/列表浏览 PDF；一点开内置阅读器；索引或仅打开；断链检测与路径修复

### 4.3 项目管理
- 类型：研究发文 / 工程学习 / 课题申请 / 在研课题 / 合作
- 学术阶段：选题 → 分析 → 写作 → 在投 → R&R → 接收 → 发表
- 工程阶段：待考察 → 架构拆解 → 环境搭建 → 最小复现 → 改造实践 → 已沉淀
- 通用字段：目标、预期收获、完成标准、状态、进度、下一步、路径与链接
- 工程记录：学习进展、架构、环境、关键技术、踩坑、工程决策、可复用结论；每条可记录来源与代码位置
- 申请：材料清单、DDL、结果
- 实验 Run：假设、参数 JSON、数据/代码路径、指标、结论、失败原因；关联项目与文献

### 4.4 任务
- 属性：优先级、状态、DDL、项目、关联实体（文献/实验/章节/投稿）
- 视图：今日、本周、逾期、按项目、看板

### 4.5 日历
- 事件类型：deadline / meeting / focus / leave / thesis_milestone / custom
- 视图数据：按日范围查询；与任务 DDL、会议、产出节点同步生成或手动创建

### 4.6 学术产出
- 期刊库 / 会议库（主数据：级别、分区、DDL 模板字段、备注）
- 投稿：状态机 撰写→内审→已投→返修→接收/拒稿→出版；审稿意见与回复记录
- 专利：提案→交底→申请→公开→授权/驳回

### 4.7 会议
- 议程、要点、决策、待办（一键转任务）、附件路径、关联项目

### 4.8 札记
- “札记”是笔记、想法、Inbox 的统一入口，三类内容保持独立语义和数据
- 笔记分为普通笔记、项目笔记与文献研究笔记，可按类型及关联研究项目筛选
- 普通笔记使用独立数据，可自由维护标题、标签和 Markdown 正文，不强制关联项目或文献
- 项目笔记可在札记页直接新建和编辑；文献笔记复用阅读文献中的结构化笔记
- 想法继续使用 ideas 数据与原有类型、状态、标签和实体关联
- Inbox 可转想法、任务、文献笔记，或归档/删除
- 笔记和想法均采用非弹窗双栏 Markdown 源码/预览编辑器；兼容标准公式分隔符及独立方括号公式块

### 4.9 毕业论文
- 节点时间线、章节树与状态、每章关联文献/实验/任务、问题清单、规范 Checklist

### 4.10 导入导出
- 导出：ZIP（`data.db` 元数据 JSON + 可选附件清单；默认导出数据库与 JSON 快照）
- 导入：校验后恢复/合并（本版采用「替换当前库」与「合并跳过同 ID」两种模式）

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 部署 | 本机 `uvicorn` 启动，浏览器访问 `http://127.0.0.1:8787` |
| 数据 | SQLite，目录 `data/` |
| 性能 | 文献列表千级可翻；PDF 流式本地打开 |
| 安全 | 仅监听 localhost；无外网账号 |
| 备份 | 一键导出 ZIP |
